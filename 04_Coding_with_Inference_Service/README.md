# Coding with the Inference Service

Use a coding agent (OpenCode or Claude Code) backed by open-weight models on the
[ALCF Inference Service](https://docs.alcf.anl.gov/services/inference-endpoints/).

- `presentation/` - slides (`make` builds `presentation.pdf` with XeLaTeX)
- `PROMPT.md` - the crash-course exercise: the Monte Carlo pi prompt, how to check
  the result, and follow-up prompts
- `solution.py` - a reference solution; run it with `python solution.py` from the
  repo's activated `.venv`
